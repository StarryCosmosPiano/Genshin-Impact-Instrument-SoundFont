# Filenames and translations / 文件改名与中英对照

[English README](../README.md) · [中文说明](../README.zh-CN.md)

English instrument names are used for all published SoundFont filenames. Only the two original-with-chords variants have a parenthetical suffix. Full-range coverage is documented in the README rather than appended to filenames.

发布的音源文件统一使用英文乐器名称。只有两个原版带和弦版本添加括号后缀；全音域信息在说明中标注，不写入文件名。

“风物琴” is the source collection's short name for **Windsong Lyre / 风物之诗琴**. “谐律钢琴” corresponds to **Harmonic Keys / 谐律键琴**, also confirmed by the embedded preset name. **Vodyanitsa / 沃雅妮莎** is a vocal SoundFont. Windows filenames omit the decorative quotation marks around “Lingering Euphonia”.

原文件中的“风物琴”是 **Windsong Lyre／风物之诗琴** 的简称；“谐律钢琴”对应 **Harmonic Keys／谐律键琴**，文件内预设名也为 Harmonic Keys。**Vodyanitsa／沃雅妮莎** 是人声音源。为兼容 Windows 文件名，Lingering Euphonia 的文件名不包含名称外的装饰性引号。
